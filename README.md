## GitHub Se APK Kaise Banayein (Step-by-Step):
1. [GitHub.com](https://github.com) par login karein aur **New Repository** banayein (e.g., `shadow-vale-rpg`).
2. Is ZIP (`ShadowVale_GitHub_APK_Builder.zip`) ko apne phone ya PC par **Extract (Unzip)** karein.
3. GitHub repo mein **Add file → Upload files** par click karein aur extracted folder ki **saari files aur folders** (`.github`, `app`, `build.gradle`, `settings.gradle`, `gradle.properties`, `index.html`) drag-and-drop karke **Commit changes** daba dein.
4. Ab apne GitHub repository ke upar **`Actions`** tab par click karein.
5. Wahan **"Build Android APK (Pawar Ji Gaming)"** workflow chal raha hoga (2–3 minute mein green tick ✅ aa jayega).
6. Workflow par click karein, neeche **Artifacts** section mein **`ShadowVale-EmberQuest-Android-APK`** par click karke apna `.apk` download aur install kar lein!
